## Interface / API Contract
- **Multi-stage Dockerfile** in `src/Dockerfile`
- **Base image**: Python 3.12 alpine (meets <100MB size requirement)
- **Builder stage**: install dependencies via pip with `--no-cache-dir` to virtual environment
- **Runtime stage**: copy virtual environment, non-root user (UID 10001), curl for health check
- **Expose**: port 8080, ENV PORT=8080
- **Health check**: `HEALTHCHECK --interval=30s --timeout=3s --start-period=5s --retries=3 CMD curl -f http://localhost:8080/health || exit 1`
- **Image size**: < 100MB
- **Dockerignore**: exclude `.git`, `__pycache__`, `.pytest_cache`, `tests/`, `*.pyc`, `.venv/`, `*.egg-info/`, `dist/`, `build/`
