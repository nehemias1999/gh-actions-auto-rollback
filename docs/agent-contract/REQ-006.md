## Interface / API Contract
- **Rollback Script** `scripts/rollback.sh` (executable, `#!/usr/bin/env bash`):
  - Args (long flags only): `--new-container` (required), `--old-container` (required), `--health-url` (required); `-h/--help` prints `usage()` to STDOUT, exit 0.
  - Behavior:
    1. Stop + remove new container (`docker stop`, `docker rm`); tolerate already-stopped/removed (idempotent).
    2. Verify old container running via `docker ps`; if stopped but exists, `docker start` it.
    3. Run health check on old container by invoking `healthcheck.sh --url <health-url>` (same retries/timeout flags exposed optionally: `--retries`, `--interval`, `--timeout` passthrough with same defaults).
    4. Exit 0 on successful rollback (old healthy); exit 1 if old container missing or fails health check; exit 2 usage error.
  - Logging: every action with timestamp (`date '+%Y-%m-%dT%H:%M:%S%z'`) → STDOUT; errors → STDERR.
  - Idempotent: re-running after a completed rollback exits 0 (new already gone, old healthy).
  - Docker CLI is a required dependency; if `docker` is missing, exit 1 with clear STDERR message.
- **Bats tests** `tests/rollback.bats`: hermetic — stub the `docker` CLI (function override emitting canned `docker ps` output + tracking stop/rm/start calls) and stub `healthcheck.sh` invocation OR run against local stub HTTP servers. Cover: successful rollback, old container down (start path), old container unhealthy (exit 1). Do NOT require a real Docker daemon.
