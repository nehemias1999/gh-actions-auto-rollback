## Interface / API Contract
- **Healthcheck Script** `scripts/healthcheck.sh` (executable, `#!/usr/bin/env bash`):
  - Args (long flags only): `--url` (required), `--retries` (default 10), `--interval` (default 3s), `--timeout` (default 2s); `-h/--help` prints `usage()` to STDOUT, exit 0.
  - Behavior: HTTP GET to `--url` with `curl --silent --max-time <timeout>`; success = HTTP 200 AND body `{"status": "healthy"}` (parse with `jq` if available, else exact grep).
  - Retry up to `--retries` with `--interval` sleep between attempts.
  - Logging: attempt number, response code, timing → STDOUT; errors/validation → STDERR.
  - Exit codes: 0 success, 1 failure after retries exhausted, 2 usage error (documented in header).
  - Idempotent, no side effects.
- **Bats tests** `tests/healthcheck.bats`: success path, timeout path, retry-exhaustion path (use local stub server or unreachable port; do NOT require the real app image — keep tests hermetic, e.g. `python3 -m http.server` stub or `nc`).
