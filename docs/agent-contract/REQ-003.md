## Interface / API Contract
- **CI Workflow** in `.github/workflows/ci.yml`
- **Trigger**: `pull_request` to `main` branch
- **Jobs**:
  1. **lint**: ruff check on Python code
  2. **typecheck**: mypy on Python code
  3. **test**: pytest with coverage (≥80% threshold)
  4. **docker-build**: build Docker image with tag `gh-actions-auto-rollback:pr-${{ github.event.number }}`
  5. **health-check**: run container, curl /health, stop container
- **Tools**: `actions/setup-python`, `actions/cache` for pip, `docker/build-push-action` (load only)
- **Validation**: yamllint .github/workflows/ci.yml passes
